# Third-party components and data

This repository contains only project source code. It depends on the Python packages pinned in `pyproject.toml` and `requirements-core.lock`, including PyTorch, NumPy, SciPy, scikit-learn, ripser, and matplotlib. Their licenses are governed by their respective projects; installation fetches those packages separately.

DroneDetect V2 is not included. Obtain it manually from the [IEEE DataPort V2 record](https://ieee-dataport.org/open-access/dronedetect-dataset-v2) and review its access and reuse conditions before using it. No dataset license or permission is asserted here.

No pretrained weights, checkpoints, notebooks, PDF articles, or third-party figure assets are included.
